# Pacman-Inspired Game AI — Case Study

An academic Unity game-AI exercise based on a maze-chase game. The work focused on agent behaviour
within a real-time game loop, including player/ghost interaction and score or game-state feedback.

## Scope

The available submission is a Unity package, not a clean standalone source repository. It contains
resources and project material whose ownership and redistribution terms have not been individually
verified. This repository therefore provides a safe portfolio description only.

## Technical themes

- real-time agent behaviour in a grid-like maze;
- game-state transitions and player interaction;
- enemy-agent roles and movement logic;
- Unity scripting and scene integration;
- incremental academic milestones.

## Deliberately excluded

- the Unity project and exported package;
- C# scripts, scenes and prefabs;
- sprites, fonts, audio and other third-party assets;
- reports, screenshots and recordings;
- local configuration, credentials and personal contact details.

## Status

This repository remains private. A future public implementation would need to be recreated as a
clean-room demonstrator with original assets or assets whose licences are explicitly compatible
with redistribution.

## Attribution

This documents an academic team deliverable. It does not attribute individual ownership of
particular game or AI components.
